1. مقدمة

نحن في مدرسة الصفا الخاصة نلتزم بحماية خصوصية أولياء الأمور والطلاب والموظفين والمستخدمين الذين يتعاملون مع خدماتنا الرقمية. هذه السياسة توضح أنواع المعلومات التي قد نجمعها، وسبب جمعها، وكيفية استخدامها، ومتى قد نشاركها، وما هي حقوقك المتعلقة ببياناتك.

2. المعلومات التي قد نجمعها

قد نقوم بجمع بعض أو كل المعلومات التالية عند استخدام التطبيق أو الموقع أو الخدمات الرقمية:

  • اسم الطالب أو ولي الأمر.
  • رقم الهاتف، البريد الإلكتروني، والعنوان.
  • بيانات حساب المستخدم في التطبيق أو الموقع.
  • معلومات التعلم أو الأداء الأكاديمي عند الضرورة.
  • معلومات الاتصال والرسائل داخل التطبيق.
  • معلومات الجهاز مثل نوع الجهاز وإصدار النظام.
  • بيانات الاستخدام، مثل تفاعل المستخدم مع التطبيق أو الموقع.
  • الأذونات التي يوافق المستخدم على منحها مثل الوصول إلى الصور أو الموقع عند الضرورة.

3. كيفية جمع المعلومات

يمكن جمع المعلومات بشكل مباشر من المستخدم عند:

  • تسجيل الحساب أو تسجيل الدخول.
  • ملء النماذج داخل التطبيق أو الموقع.
  • التواصل مع الإدارة أو المعلم أو الدعم الفني.
  • استخدام الخدمات التعليمية أو الإدارية داخل التطبيق.
  • تفاعلك مع النظام أو الرسائل الإلكترونية أو الإشعارات.

4. استخدام المعلومات

نستخدم المعلومات التي نجمعها لغرض مهم وحصري، ومن بينها:

  • توفير الخدمات التعليمية والإدارية للمستخدمين.
  • إدارة الحسابات والاشتراكات والنتائج الدراسية.
  • تسهيل التواصل بين المدرسة وأولياء الأمور أو الطلاب.
  • تحسين تجربة المستخدم داخل التطبيق أو الموقع.
  • تقديم الدعم الفني والخدمات المتعلقة بتسجيل الدخول أو الحسابات.
  • تلبية المتطلبات القانونية والتنظيمية.

5. مشاركة المعلومات

لا نبيع أو نؤجر البيانات الشخصية للمستخدمين. قد نقوم بمشاركة المعلومات مع جهات موثوقة فقط عند الضرورة لتقديم الخدمة، مثل:

  • مزودي خدمات الحوسبة السحابية والاستضافة.
  • أدوات التحليل والإحصاءات اللازمة لتحسين الخدمات.
  • مقدمي خدمات الدعم التقني أو الرسائل أو الإشعارات.
  • جهات تنظيمية أو حكومية عند الطلب أو عند وجود التزام قانوني.

في جميع الحالات، سنحاول الحد من مشاركة المعلومات إلى الحد الأدنى الضروري لتحقيق الهدف المحدد.

6. التخزين والحماية

نتخذ تدابير مناسبة لحماية بياناتك من الوصول غير المصرح به أو التعديل أو الفقدان أو الاستخدام غير القانوني. ومع ذلك، لا توجد طريقة نقل أو تخزين إلكتروني بنسبة 100% آمنة، لذلك نحث المستخدمين على اتخاذ الاحتياطات اللازمة للحفاظ على سرية حساباتهم.

7. الاحتفاظ بالبيانات

نحتفظ بالبيانات الشخصية فقط لفترة زمنية معقولة تتوافق مع أغراض جمعها، أو وفقًا للمتطلبات القانونية والتنظيمية المعمول بها. عندما لا تكون البيانات مطلوبة، سنقوم بحذفها أو إخفائها بشكل مناسب.

8. حقوق المستخدم

لكل مستخدم الحق في:

  • طلب الوصول إلى بياناته الشخصية.
  • طلب تصحيح أي معلومات غير دقيقة أو غير كاملة.
  • طلب حذف بياناته في بعض الحالات، وفقًا للقوانين المعمول بها.
  • الاعتراض على معالجة بياناته في ظروف محددة.
  • سحب موافقته على معالجة البيانات متى كان ذلك ممكنًا.

يمكن تقديم هذه الطلبات عبر التواصل مع المدرسة من خلال البريد الإلكتروني أو الهاتف المذكور في التطبيق أو الموقع الرسمي.

9. الإشعارات والتحديثات

قد نعدل هذه السياسة من وقت لآخر لإضافة أو تحديث المعلومات أو لتلبية التغييرات التنظيمية أو التشغيلية. سيتم إخطار المستخدمين بأي تغييرات مهمة عبر التطبيق أو الموقع أو البريد الإلكتروني عند الحاجة.

10. خصوصية الأطفال

نأخذ بعين الاعتبار خصوصية الأطفال والطلاب دون سن البلوغ. لا نجمع أو نستخدم بيانات الأطفال إلا عند الضرورة لتقديم الخدمة التعليمية أو وفقًا للأهل أو الوصي القانوني. إذا كان التطبيق أو الخدمة قد يطلب بيانات أو أذونات خاصة بالأطفال، فسنعمل على تقليلها إلى الحد الأدنى وتوفير الشفافية.

11. ملفات تعريف الارتباط (Cookies)

قد نستخدم ملفات تعريف الارتباط أو تقنيات مماثلة لتحسين تجربة المستخدم، تحليل الأداء، وتسجيل تفاعل المستخدم مع التطبيق أو الموقع. يمكنك إدارة إعدادات المتصفح لرفض ملفات تعريف الارتباط أو حذفها، مع ملاحظة أن ذلك قد يؤثر على بعض الوظائف.
